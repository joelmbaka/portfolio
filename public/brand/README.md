# Bridgeframe V2 — Joeltech Geek Systems

This is the **approved** logo for the Kenya-based software development company Joeltech Geek Systems.

## Art direction
A dark/white upper structure and emerald lower structure are connected by a gold diagonal bridge. Preserve proportions, negative space and the three brand colors in all digital uses.

- Light surface: `bridgeframe-icon-on-light.svg`, `bridgeframe-logo-on-light.svg`
- Dark surface: `bridgeframe-icon-on-dark.svg`, `bridgeframe-logo-on-dark.svg`
- Black/white: `bridgeframe-icon-black.svg`, `bridgeframe-icon-white.svg`
- Favicon: `bridgeframe-favicon-dark.svg`, `bridgeframe-favicon-light.svg`
- Browser shortcut: `app/favicon.ico`, vector browser icon: `app/icon.svg`
- Home screen and PWA: `bridgeframe-180.png`, `bridgeframe-192.png`, `bridgeframe-512.png`

The navbar/footer use an accessible native-text lockup with the approved vector mark for reliable rendering at small sizes. The exported SVG wordmarks remain editable for Figma, print and marketing collateral.

Do not change the hero portrait here; problem-solving hero imagery is a separate design project.
